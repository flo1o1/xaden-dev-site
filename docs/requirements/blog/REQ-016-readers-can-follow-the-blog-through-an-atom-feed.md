# Readers can follow the blog through an Atom feed (second step)

## Job

When I want to follow Xaden, I want an Atom feed, so I can read new posts in my feed reader without being tracked.

## Acceptance criteria

- Given the blog, then /index.xml or an equivalent Atom feed lists the posts with title, date and link
- Given the feed, then it is a static file and the page advertises it with a link element
