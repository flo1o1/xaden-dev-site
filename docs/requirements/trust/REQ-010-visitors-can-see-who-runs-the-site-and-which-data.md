# Visitors can see who runs the site and which data is processed

## Job

When I visit the site, I want to find who is responsible for it and how my data is handled, so I can contact the provider and know what I agree to.

## Acceptance criteria

- Given the footer of every page, then it links to the imprint and the privacy notice
- Given the imprint, then it shows name, business address, email and occupation (VAT ID if one exists)
- Given the privacy notice, then it names GitHub Pages as host and states that visitor IP addresses are processed there
- Given both texts, then they are in English and reviewed by the owner before launch
