# Contributors find how to contribute, test and open pull requests (second step)

## Job

When I want to contribute to Xaden, I want to know how to contribute, run the tests and land a change, so I can send a good first change.

## Acceptance criteria

- Given the Contributors pages, then they answer: how to contribute, how to test, Xaden's own flow for landing a change (branch, CI green on the exact commit, pull request)
- Given the docs menu, then a Contributing section sits next to the guides, below Reference, and its pages (install with git, architecture, work on Xaden, release and signing, threat model and requirements) are generated from the Xaden release like the guides; a release that does not carry them yet leaves the section empty instead of failing
- Given the guides, then they describe no manual zip download, verification and extraction as an install route
