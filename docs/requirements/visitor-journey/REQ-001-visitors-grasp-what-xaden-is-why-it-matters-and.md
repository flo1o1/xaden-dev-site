# Visitors grasp what Xaden is, why it matters and how to start within a minute

## Job

When I land on the home page from a link or a search, I want to see what Xaden is, what problem it solves and how to install it, so I can decide in about a minute whether to try it.

## Acceptance criteria

- Given the home page, when read top to bottom, then it has the sections What, So what and Now what, in that order
- Given the Now what section, then it shows the prerequisites, the install command and one primary link to Getting Started
- Given the prerequisites on the home page, then they name the supported operating systems (Linux, macOS) and the Windows status (WSL or Git Bash, untested), consistent with the Getting Started page
- Given the What section, then it shows real terminal output of creating a project, not a mock-up
- Given any claim on the home page, then it links to the doc page or file that backs it
- Given the So what section, then it names who Xaden is not for
