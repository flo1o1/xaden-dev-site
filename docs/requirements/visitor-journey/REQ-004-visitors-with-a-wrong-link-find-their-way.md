# Visitors with a wrong link find their way

## Job

When I follow an outdated or mistyped link, I want a helpful not-found page, so I can continue to the home page or the docs instead of leaving.

## Acceptance criteria

- Given an unknown URL, when requested, then the 404 page is shown with links to Home and Docs and the HTTP status is 404
