Start with [Getting started]({{< relref "docs/getting-started" >}}). The pages below are rendered
from the Xaden release named on each page; unreleased changes do not appear.

## Admins

- **Install**: [Prerequisites]({{< relref "docs/getting-started" >}}#1-prerequisites) and
  [the `xaden` command]({{< relref "docs/getting-started" >}}#optional-the-xaden-command). Steps per
  operating system and the zip and clone install ways follow with the next Xaden release.
- **Update**: [in an existing project]({{< relref "docs/getting-started" >}}#getting-scaffold-improvements-into-your-project).
  Versions follow [Semantic Versioning](https://semver.org/): a patch release fixes, a minor release
  adds, a major release may break.
- **Uninstall**: [`scripts/install.sh --uninstall`]({{< relref "docs/getting-started" >}}#optional-the-xaden-command)
  removes the `xaden` link; delete the folder afterwards.
- **Keep it secure**: [Security checklist]({{< relref "docs/security" >}}).
- **What is inside**: [Optional tools]({{< relref "docs/optional-tools" >}}) lists the tools and plugins Xaden works with.
